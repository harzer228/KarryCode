# Create project

1. Inspect the folder and check for filename collisions.
2. Pick the simplest stack that satisfies the brief. Ask about a choice only when it changes the outcome.
3. Use create_file for one new file and apply_changes for a complete project. Include a README, a runnable entry point and a test of the main behavior.
4. Run its test and launch it through an approved tool. Explain what was verified and provide the launch command.
