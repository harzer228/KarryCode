---
name: design-console
description: Customize KarryCode colors, layout, panel widgets and interface translations in an approved appearance package.
---

Work in a Creator draft. Load the package guide with `extension_author(operation="guide")`. Compose a restrained palette and a layout that fits a narrow terminal. Keep buttons specific and route them through an approved tool or a built-in panel command.

Use the message IDs from `/theme` for a new dictionary and preserve the original placeholders. Verify the package with `extension_author(operation="validate")`. After installation, preview it through `/theme` and check both the keyboard path and a smaller terminal. Use `--safe-ui` to recover the built-in console if necessary.
